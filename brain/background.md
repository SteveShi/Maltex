# Project background

Maltex is a native macOS download manager and acceleration tool built in SwiftUI. It provides multi-threaded chunked downloads, queue management, and network monitoring.

## Goals
- Lightweight, native macOS alternative to bloated Electron download managers.
- Accelerated multi-connection file downloads with auto-resuming.
